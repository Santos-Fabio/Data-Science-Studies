# Data-Science-Studies
## AI Usage and Impact on Students & Professionals – Exploratory Data Analysis
A repository for data science studies, focused on reading, analyzing, and working with different datasets.

## About the Project

This project aims to explore and analyze data related to the use of Artificial Intelligence tools by students and professionals. The goal is to identify usage patterns and investigate potential relationships between AI adoption, productivity, time savings, and user satisfaction.

The analysis is being developed in Python using data cleaning, exploratory data analysis (EDA), and data visualization techniques.

## Dataset

The dataset used in this project was obtained from Kaggle.

**Source:** https://www.kaggle.com/datasets/eishatuzzuhra/ai-usage-and-impact-on-students-and-professionals/data


It contains information about user profiles, AI tool usage, costs, time savings, satisfaction levels, and recommendation behavior.

## Technologies Used

- Python 3.14.8
- Pandas — data manipulation and analysis
- NumPy — numerical operations
- Matplotlib — data visualization
- Seaborn — statistical visualization

## Project Workflow

### 1. Initial Data Exploration

- Inspected the dataset structure and dimensions.
- Reviewed data types and descriptive statistics.
- Identified duplicate records and missing values.

### 2. Data Cleaning and Preparation

- Removed duplicate records.
- Standardized text formatting (lowercase, trimmed spaces, and whitespace normalization).
- Converted numerical columns to appropriate data types.
- Standardized categorical values.
- Investigated missing values for further treatment.

### 3. Exploratory Data Analysis

Current analyses focus on understanding the distribution of variables and exploring relationships between user satisfaction and recommendation behavior.

Additional visualizations and statistical analyses will be implemented as the project progresses.
